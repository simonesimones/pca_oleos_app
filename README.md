# Toolbox PCA + HCA
Execute `py -m pip install -r requirements.txt` e `py -m streamlit run app.py` no Windows. No Streamlit Cloud, envie app.py, core.py e requirements.txt para a raiz do repositório.
Planilha: cabeçalhos na primeira linha, uma amostra por linha; selecione explicitamente as variáveis ativas. Arquivo suplementar separado exige identificadores únicos coincidentes. Pesos multiplicam as colunas após centralização ou autoescalamento (desvio padrão amostral). Não há imputação automática. PCA por SVD com exclusão de direções numericamente nulas. Limites T² e Q são quantis empíricos internos, não inferenciais. HCA usa a matriz pré-processada. O biplot de loadings usa fator gráfico comum; o círculo usa correlações; o biplot suplementar usa scores normalizados e correlações. Não há pressuposição de sazonalidade. Dados de teste são sintéticos. Para dados composicionais, avalie transformações log-ratio antes de usar a ferramenta. Não publique dados confidenciais no repositório.
